# blocklist
A blocklist for the [Hashbrown](https://git.tuffaceous.dev/hashbrown/about/) discord bot, complete with an Actions workflow for super easy maintenance.

This list is pretty small at the moment!!

If you have encountered a malicious image that you think is both common
and was sent by a hijacked account, feel free to make a [pull request](https://github.com/hillsawer/blocklist/pulls) with that image attached.
